# RecyCraft downloads and screenshots

This public repository hosts the downloadable RecyCraft 1.0 JAR and four screenshots for the Spigot resource page. The source repository remains private.

The compact JAR uses Spigot's `plugin.yml` library loader to download SQLite JDBC and SLF4J from Maven Central when the server first starts. The server requires Internet access for this step. This specific compact JAR has been compiled but has not been tested in a running server.
